# Планировщик задач (Дипломный проект)

Веб-приложение для управления списком задач с поддержкой повторяющихся событий и поиском.

## Описание

Планировщик позволяет:
- Добавлять, редактировать, удалять и отмечать задачи как выполненные.
- Настраивать повторение задач: ежедневно (`d N`), ежегодно (`y`).
- Искать задачи по заголовку, комментарию или дате (в формате `DD.MM.YYYY`).
- Хранить данные в локальной SQLite-базе (`scheduler.db`).

Приложение состоит из:
- Backend на Go (REST API)
- Frontend (статические HTML/CSS/JS файлы в папке `web/`)

## Выполненные задания со звёздочкой

- ✅ Поиск задач по тексту и дате (`/api/tasks?search=...`)
- ✅ Поддержка всех базовых правил повторения (`d N`, `y`)
- ✅ Валидация даты и автоматическая коррекция (если дата в прошлом)
